Backup & data tools owner only

Backup

Downloads every record as one JSON file. Do this weekly and after big changes.

Restore from backup

Merge adds/updates records from the file, keeping everything else. Replace deletes all financial records first, then loads the file. Login accounts can never be recreated from a backup — only their records.

Date-range reset

Deletes financial records inside the period. Deleting a request also deletes its repayments (whatever their date). The audit log is never deleted.

System check

Run this if uploads or charts misbehave. It reports what the database currently allows your account to do.
